# Milestone 01 — LDOE Movement & Camera Calibration

Deliver a playable procedural test scene focused only on player scale, camera, responsive camera-relative movement, deterministic sliding collisions, shadows, debug visualization, and live calibration.

Controls: WASD/arrows or virtual joystick. F1 toggles calibration; F2 toggles diagnostics. No inventory, harvesting, combat, AI, crafting, building system, or persistence beyond calibration values.

Completion requires a clean production build and runtime verification in a browser.
