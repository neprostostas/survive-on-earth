# Rules for Agents

1. Read `ARCHITECTURE.md` before working.
2. Read the current milestone before working.
3. Do not implement the next milestone independently.
4. Do not rewrite working systems without necessity.
5. Do not change another system's public API without a reason.
6. Explain why before changing the architecture.
7. One milestone is one controlled task.
8. `npm run build` must pass after every task.
9. Leave no TypeScript errors.
10. Leave no console errors.
11. Do not create duplicate implementations.
12. Do not add dependencies without real need.
13. Do not build speculative future systems.
14. Do not implement features absent from the task.
15. Keep gameplay constants centralized.
